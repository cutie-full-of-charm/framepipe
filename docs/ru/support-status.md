# Состояние поддержки и план развития

> Версия при написании: `0.4.2.dev4`  

## Ближайшие направления улучшений

Feel free to contribute, create issues, etc.

- Переработать обработку ошибок у декодера, сейчас имеются сотни throw, часть из которых роняет поток, и заставляет его пересоздаться, хотя этого можно и избежать. При некорректной конфигурации пайплайна декодер вообще падает в loop ошибки, т.к. без конца не может восстановиться из-за некорректной конфигурации, этот пункт приоритет №1.
- Сделать явное указание CUDA девайса.
- Разделить сборку CUDA/CPU и убрать обязательность CUDA Toolkit для CPU/VAAPI-only конфигурации.
- Улучшить поддержку разных цветовых метаданных для CPU, VAAPI и CUDA; расширить GPU-конвертацию для разных матриц и full-range.
- Добавить дополнительные входные sw_format/10-bit и расширить Python-доступ к нативным planar-форматам.
- Сделать выбор VAAPI render node настраиваемым.
